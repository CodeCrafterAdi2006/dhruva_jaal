📱 1. Civilian & Dongle Tier

Turns ordinary smartphones into off-grid emergency communicators with zero cellular infrastructure.

  • $8 Hardware BOM: ESP32-C3 Super Mini ($3.20) + Semtech SX1278 Ra-02 ($3.80) + internal 433MHz helical antenna.
  • USB CDC-ACM Link: Plugs directly into Android USB-C OTG port (draws ~35mA listening current).
  • Offline PWA (survivor_app/): React 18 + Tailwind client running in Chrome via Web Serial / WebUSB API.
  • Zero Confusion UX: One-tap SOS, 5s cancel window, medical/trapped flags, and live GPS stamping.

📻 2. Mesh & Firmware Tier

Deterministic C++ firmware (firmware/) guaranteeing packet persistence during network destruction.

  • Store-and-Forward Flash (store.cpp): 1.43MB circular flash buffer caching 24,000+ SOS records when downstream links drown.
  • Slotted CAD MAC (mac.cpp): 12.3ms Carrier Activity Detection + jittered backoff prevents broadcast storms.
  • Geographic Forwarding: Local score router ranks neighbors by distance to HQ, RSSI, and aerial elevation bonus.
  • Two-Way Cryptographic ACK: Survivor node turns GREEN only upon verified ACK delivery from Base Camp.

🚁 3. Two-Tier Aerial & 3D Twin

Tactical Command Center (frontend/) running 60 FPS WebGL 3D terrain and autonomous fleet optimization.

  • Strict 6-Drone Ceiling: Realistic disaster logistics limit active drones to 6 to prevent airspace collisions and battery depletion.
  • Steiner Midpoint Gap Solver: Clusters isolated nodes and computes optimal airborne relay bridge coordinates.
  • Auto Aerostat Relief: If gaps exceed 6, stationed drones are automatically relieved by 100m tethered balloons.
  • Procedural Audio: Pure Web Audio API synthesizing real LoRa Chirp Spread Spectrum (800Hz→2400Hz) sweeps.

1st Fresnel Zone ($F_1$) $F_1 = 8.656\sqrt{d_{\text{km}}/0.433}$ Ground link obstructed (<20% clearance); 100m aerostat achieves 96% LoS.
Geographic Score $0.5\cdot\Delta d + 0.3\cdot\text{RSSI} + 0.2\cdot\text{Alt}$ Dynamically steers packets towards HQ without full routing tables.
